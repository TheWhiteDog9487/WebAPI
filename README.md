# 命令行参数
| 参数 | 说明                                                       |
|---|------------------------------------------------------------|
| `install` / `--install` | 安装为 systemd 服务                   |
| `uninstall` / `--uninstall` | 卸载 systemd 服务                    |
| `--Discord_Bot_Token <令牌>` | 设置 Discord 机器人令牌，优先级高于同名环境变量            |
| `--Disable-Discord` | 安装systemd服务时禁用 Discord 相关功能，故不再要求提供令牌 |
